# Rudy LogProof 0.1.0 preview

Offline Go Merkle log verification for ordered release evidence. Authenticate Ed25519 checkpoints against a pinned public key and saved anchor, verify every consistency transition and inclusion path, and apply explicit freshness limits.

Native Windows x64, Linux x64, and macOS ARM64 packages include synthetic signed fixtures, schema documentation, and Go runtime license notices. Verify each archive against its SHA-256 manifest entry.
